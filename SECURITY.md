# Security policy

## Scope

The Research Methods Library is a read-only service. Its tools search and return
published book sections, code, and citations; they write nothing, call no language
models, and store no information about users. The hosted endpoint is
https://research-methods-mcp.vercel.app/mcp.

## Supported versions

Security fixes are made on the `main` branch, which the hosted endpoint deploys
from, and in the latest published release.

## Reporting a vulnerability

Please report suspected vulnerabilities by opening an issue at
https://github.com/mikenguyen13/research-methods-mcp/issues with "Security" in the
title. If the report includes details that should not be public, say so in the
issue without the details, and a private channel will be arranged.

Reports are acknowledged within five business days.
